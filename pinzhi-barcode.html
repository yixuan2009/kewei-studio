FEATURES · 功能FEATURES

应用功能介绍What the app does

六大核心能力，覆盖从识别到导出的完整制码流程。 Six core capabilities covering the full barcode workflow — from scanning to export.
01

条形码生成Barcode Generation

Barcode Generation

支持 Code 128 / EAN-13 / UPC / Code 39 等常用一维条码，输入即得高清矢量图。 Supports Code 128 / EAN-13 / UPC / Code 39 and more — vector output ready for print.

02

二维码生成QR Code Creation

QR Code Creation

支持文本、网址、Wi-Fi、名片、邮件等内容类型，可自定义颜色、嵌入 Logo。 Text, URL, Wi-Fi, vCard, email — customize colors and embed your own logo.

03

扫码识别Scan & Recognize

Scan & Recognize

实时摄像头扫码，亦支持从相册图片中识别，可在弱光环境下保持稳定。 Real-time camera scanning or recognize from photo library — stable even in low light.

04

批量生成Batch Generation

Batch Generation

导入 Excel 或 CSV 一次生成数十至数百条码，自动编号、自动排版。 Import Excel/CSV to generate dozens or hundreds at once — auto-numbered and laid out.

05

历史记录History

History

所有生成与扫描记录本地保存，支持标签、搜索、收藏与一键重新生成。 Generation & scan history stored locally — search, tag, favorite, and regenerate in one tap.

06

多格式导出Multi-format Export

Multi-format Export

一键导出为 PDF、Excel 或保存至相册，支持 AirDrop、邮件与打印工作流。 Export to PDF, Excel, or Photos in one tap — works with AirDrop, Mail, and print workflows.
